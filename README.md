# Exercícios de POO em Java

Lista de Programação em Java — Banco de Dados.

- `dominio/` reúne as classes de domínio.
- `test/` reúne os 50 exercícios executáveis.

No IntelliJ, marque a pasta que contém `dominio` e `test` como Sources Root. Abra a classe desejada e execute o método `main`.

## Código Java

Clique no nome de um arquivo para abrir o código no GitHub.
